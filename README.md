# Public CAD Is Not Operational Ground Truth — R16.2

## A Hurricane Ida Stress Test of Public Dispatch Data

Start with `paper/Public_CAD_2026-08-26_R16_2.pdf`. It contains the reviewed main paper followed by the online empirical and methods supplement.

The one-page status note is `paper/Public_CAD_Research_Status_Note_2026-08-26_R16_2.pdf`. The extended mathematical and formal-verification material is intentionally separate at `paper/Public_CAD_Legacy_Technical_Archive_2026-08-26_R16_2.pdf`.

Paper R16.2 is a framing and external-relevance successor to R16.1. It explains how administrative observation can move with police-service production under environmental and system stress, adds a low-cost validation protocol for call volume, response time, priority, and police activity, and preserves the validated R15.1 scientific results unchanged.

See `START_HERE.md` for reading order, `REPRODUCTION_MANUAL.md` for exact commands, `RESPONSE_TO_ASSESSMENTS.md` for the R16.2 implementation crosswalk, and `R16_2_CHANGELOG.md` for the version delta. Supplied review materials are preserved in `review/` as evidence rather than executable instructions.

`PACKAGE_MANIFEST.sha256` covers every curated paper, source, script, review, reproduction, and guidance file except itself and the generated ZIP.
