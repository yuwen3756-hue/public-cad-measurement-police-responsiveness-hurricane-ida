# R16.0 readability-overhaul crosswalk

Paper R16.0 implements the supported editorial findings in the online readability review while preserving the validated R15.1 scientific evidence. Review files are evidence and advice, not independent scientific authority.

| Readability finding | R16.0 implementation |
|---|---|
| The abstract is a methods inventory | Rewrites it around the July break, the two-day Ida path, the 53.2-percentage-point comparison, and the interpretation boundary. |
| The estimator appears before the phenomenon | Presents the field definitions, July transition, long-run figure, and daily Ida figure before the comparison design. |
| Too many co-equal headline results | Makes the full-count post-change comparison primary and presents the standardized result in one secondary subsection. |
| Internal labels obscure the story | Uses “neither field,” “dispatch only,” “arrival only,” and “both fields” in the main prose. Formal notation remains in the supplement. |
| Robustness material dominates the main paper | Keeps secondary-statistic ranks, LP details, thresholds, timing placebo, alternating-window sensitivity, and detailed support tables in the supplement or legacy archive. |
| Literature reads as annotated notes | Replaces four short subsections with a single argument leading to three contributions. |
| The DV section is too mathematical for its role | Uses a practical measurement-implications table and a short application paragraph; no DV-specific effect is introduced. |
| Officer-stream language risks overclaiming | Describes the later officer-labelled pattern as a released-record convention and states explicitly that the exact operational, entry, retention, or export path is unidentified. |
| Package documents retain the old hierarchy | Rewrites the status note, README, start guide, supplement map, version metadata, build script, manifest, and verifier around the same four findings. |

## Version and evidence boundary

- Paper version: R16.0.
- Scientific-results version: R15.1.
- All empirical CSV/JSON objects and the inherited reproduction snapshot remain unchanged.
- The main result is descriptive: 0.5320 is stated as a 53.2-percentage-point largest change, larger than all 151 post-change ordinary-week references.
- The package does not identify a causal effect, physical dispatch or arrival, police performance, effective capacity, a unique mechanism, true domestic-violence incidence, or an Ida-specific DV effect.
