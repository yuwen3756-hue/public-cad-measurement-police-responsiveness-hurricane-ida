# R16.1 two-review implementation crosswalk

Paper R16.1 implements the compatible textual and presentation recommendations in the two independent R16.0 reviews while preserving the validated R15.1 scientific evidence. Review files are evidence and advice, not independent scientific authority.

| Review finding | R16.1 implementation |
|---|---|
| Supplement contains a broken duplicated standardized definition | Deletes the incomplete first copy and retains one complete definition followed by its equation. |
| Figure 2 text incorrectly implies a monotone return | Reports the return by 5 September and the separate 34.7-percent excursion on 10 September. |
| The 29 August arrival-field dip is visible but undescribed | Reports the 43.8-percent valid-arrival share and contrasts it with the later missing-dispatch pattern. |
| Three public configurations are called independent | States that three of four configurations are used and that the fourth is determined because shares sum to one. |
| The recurring conditional-share phrase is difficult | Defines **public missing-dispatch share** once and uses it in the abstract, text, status note, supplement, and figure legends. |
| The abstract carries unnecessary standardized-support detail | Removes the standardized-analysis sentence while retaining the primary result and interpretation boundary. |
| Opening sentence sounds universal and conflates public with internal CAD | States that researchers commonly use CAD-system timestamps, then separately identifies the validation problem when CAD records are publicly released. |
| Introductory warning is repetitive | Combines the first two paragraphs into one question-first measurement paragraph. |
| Title page and manuscript metadata are incomplete | Adds Yuwen Zhu, Carleton University, discussion-draft status, and a public data-and-code availability statement. |
| Percentage points should precede decimal notation | States 53.2 percentage points before $M=0.532$. |
| Safe-interpretation table repeats field labels | Retitles the final column around what each label does not establish. |
| Officer-stream implication can be stated more directly | States that the officer-stream break is necessarily in production of the released record while leaving the exact production step unidentified. |
| Overlapping references need their direct sensitivity in the main paper | Notes that alternating windows remove adjacent overlap and leave Ida first in both phases. |
| The missing institutional bridge needs a concrete next step | Identifies a focused OPCD public-records request for July 2021 export configuration and change history. |
| Cristobal comparison could help distinguish stress from field regime | Adds the pre-break 0.333/0.340 comparison and notes that it moves through the then-available configurations, not arrival-only records. |
| “Partial identification” is not the best keyword for this version | Replaces it with “administrative data quality.” |
| Subtitle slightly oversells what Ida reveals | Uses “A Hurricane Ida Stress Test of Public Dispatch Data.” |

The suggested new complete-case response-time analysis, second-city replication, and agency validation are not part of R16.1. They are prospective empirical extensions that would change the scientific scope rather than repair the reviewed manuscript.

## Version and evidence boundary

- Paper version: R16.1.
- Scientific-results version: R15.1.
- All empirical CSV/JSON objects and the inherited reproduction snapshot remain unchanged.
- The main result is descriptive: the 53.2-percentage-point largest change is larger than all 151 post-change ordinary-week references.
- The package does not identify a causal effect, physical dispatch or arrival, police performance, effective capacity, a unique mechanism, true domestic-violence incidence, or an Ida-specific DV effect.
