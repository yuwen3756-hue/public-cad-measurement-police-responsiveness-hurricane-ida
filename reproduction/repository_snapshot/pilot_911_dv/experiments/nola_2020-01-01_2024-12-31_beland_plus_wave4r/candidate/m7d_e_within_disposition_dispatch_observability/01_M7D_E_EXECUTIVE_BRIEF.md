# Executive brief

M7D-E separates changes in recorded-disposition mass from changes in dispatch-field observability within disposition among arrival-observed public records.

The aggregate B6-B7 changes are overwhelmingly within-disposition. Recorded composition shifts slightly offset, rather than produce, the large negative changes in $q_{all}$. The result is consistent across GOA, RTF, and NAT and is descriptively rarer than all defined 2021 frozen-reference values for each category and bin.

The analysis inherits the M5 parent universe, bins, strata, and reference weights. It introduces no disposition-specific support domain and does not reuse M7D-C closure as independent evidence.
