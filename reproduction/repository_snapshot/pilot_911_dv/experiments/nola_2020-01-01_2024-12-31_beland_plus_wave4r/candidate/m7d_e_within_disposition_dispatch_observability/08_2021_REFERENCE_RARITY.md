# 2021 reference rarity

The reference set contains 45 outcome-blind, frozen-eligible M7B windows beginning in 2021. Forty-four define each GOA, RTF, and NAT B6-B7 contrast.

Every focal $\Delta q$ is below the minimum defined reference value and has ascending rank 1 of 45 including the focal value. The add-one lower-tail fraction is $1/45=0.02222$ for each supported category-bin diagnostic.

UNF is `DESCRIPTIVE_ONLY`: the focal value is undefined and only one B6 and four B7 reference windows define it. No exchangeability claim is made.
